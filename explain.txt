1. Nessus
What is Nessus?

Nessus is a vulnerability scanner used to identify security weaknesses in systems, servers, and networks.

Why is it used?
Detect vulnerabilities
Missing patches
Weak configurations
Open ports
Compliance checks
How does it work?
Scans target systems.
Compares findings with vulnerability database.
Generates reports with severity levels.
Viva Answer

Nessus is an automated vulnerability assessment tool used to identify security flaws, misconfigurations, and missing patches in networks and systems.
